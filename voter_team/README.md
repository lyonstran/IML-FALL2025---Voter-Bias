# README for voter_cutoff

## Files in this folder:

- `unweighted`
    - includes all unweighted files and corresponding voter-team visuals for Michigan, Alabama, Oklahoma, and LSU
    
- `weighted`
    - includes all weighted files and corresponding voter-team visuals for Michigan, Alabama, Oklahoma, and LSU

- `voter_team_cutoff50`
    - all biases for voter-team pairs, cut-off at 50 total instances or higher

- `voter_team_cutoff80`
    - all biases for voter-team pairs, cut-off at 80 total instances or higher
